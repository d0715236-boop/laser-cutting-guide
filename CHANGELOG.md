# CHANGELOG

Все заметные изменения в этом проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
а проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] - 2025-11-21

### Добавлено
- Таблица стоимости услуг лазерной резки с актуальными рыночными ценами РФ на 2024–2025 гг.
- Детальный чек-лист для оценки подрядчика (12 пунктов)
- Раздел «Красные флаги» — признаки недобросовестных исполнителей (6 пунктов)
- Рекомендации по форматам файлов для заказа (✅ рекомендуемые, ⚠️ принимаемые, ❌ не подходят)
- Прямые ссылки на отфильтрованные каталоги Top-Base (лазерная резка, сварка, гравировка)
- Информация о комбинированных технологиях (резка → гибка → сварка → покраска → термообработка)
- Таблица с отраслями-потребителями и типичными изделиями

### Изменено
- Расширен раздел «Типы лазеров» детальным сравнением Fiber vs CO₂ (7 критериев)
- Обновлена таблица толщин резаемых материалов по мощностям (1.5–20+ кВт)
- Уточнены максимальные толщины для разных материалов

### Исправлено
- Уточнен КПД волоконных лазеров (30–40% вместо ~25%)
- Исправлена информация о длине волны CO₂ лазеров (10.6 мкм)

## [1.1.0] - 2025-11-20

### Добавлено
- Детальная таблица максимальных толщин по мощностям лазеров для стали, нержавейки, алюминия
- Таблица классов точности резки по ISO 9013 / ГОСТ (4 класса с допусками и шероховатостью)
- Раздел «Дефекты реза и их причины» (5 основных дефектов с решениями)
- Сравнительная таблица типов лазеров по 7 критериям
- Информация о дисковых лазерах (Disk Laser)

### Изменено
- Структурирован раздел «Материалы для резки» в виде таблицы с максимальными толщинами
- Добавлены примечания по высокоотражательным металлам и покрытым пленкой материалам

## [1.0.0] - 2025-11-19

### Добавлено
- Базовая структура справочника (11 разделов)
- Общая информация о лазерной резке из каталога Top-Base
- Принцип работы лазерной резки (5 этапов, 3 режима)
- Преимущества лазерной резки (8 пунктов в таблице)
- Типы лазеров: Fiber, CO₂ (базовое сравнение)
- Материалы для резки (основные металлы с максимальными толщинами)
- Применение в промышленности (8 отраслей)
- Базовый чек-лист выбора подрядчика
- Ориентировочные цены (базовая версия)
- Полезные ссылки на каталоги и технические ресурсы
- Форматы файлов для заказа
- Информация о лицензии и источнике данных
