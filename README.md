## Общая информация

**Лазерная резка** — это технология теплового разделения материалов с использованием сфокусированного лазерного пучка. Она обеспечивает высокую скорость изготовления деталей из листового металла. Благодаря небольшой ширине реза (обычно 0.1–0.3 мм) удается получать сложные контуры без необходимости последующей механической обработки.

### Ключевые характеристики:
| Параметр | Значение |
|----------|----------|
| **Точность позиционирования** | ±0.05 мм |
| **Повторяемость** | ±0.02 мм |
| **Ширина реза (kerf)** | 0.1–0.3 мм |
| **Макс. толщина стали** | до 25–30 мм (в зависимости от мощности) |
| **Макс. толщина нержавейки** | до 20–25 мм |
| **Макс. толщина алюминия** | до 15–20 мм |
| **Скорость резки (1 мм сталь)** | до 15–20 м/мин |

## Принцип работы

Процесс лазерной резки включает несколько этапов:

1. **Генерация излучения** — лазерный источник создает пучок высокой плотности мощности
2. **Фокусировка** — оптическая система фокусирует пучок в точку диаметром 0.1–0.3 мм
3. **Взаимодействие с материалом** — энергия поглощается, материал нагревается до температуры плавления/испарения
4. **Удаление расплава** — вспомогательный газ (кислород, азот, сжатый воздух) удаляет расплав из зоны реза
5. **Движение** — ПОУ (станок с ЧПУ) перемещает головку или стол по заданной траектории

### Режимы резки:
- **Оксидная резка (кислород)** — для углеродистой стали, экзотермическая реакция ускоряет процесс
- **Испарительная резка (азот)** — для нержавейки, алюминия, титана; чистый край без оксидов
- **Резка сжатым воздухом** — экономичный вариант для тонкого металла

## Преимущества лазерной резки

| Преимущество | Описание |
|--------------|----------|
| **Высокая точность** | Допуски ±0.05 мм, идеально ровные края |
| **Минимальная зона термического воздействия** | Малое перегревание, отсутствие деформаций |
| **Сложные контуры** | Любые формы, острые углы, мелкие отверстия |
| **Высокая скорость** | В 3–5 раз быстрее плазменной резки на тонком металле |
| **Автоматизация** | Полный цикл: CAD → CAM → CNC без участия оператора |
| **Экономия материала** | Узкий разрез, плотная компоновка деталей (nesting) |
| **Чистота реза** | Часто не требует чистовой обработки |
| **Гибкость** | Быстрая смена заказов, малые партии без переустановки |

## Типы лазеров

### 1. Волоконно-оптические лазеры (Fiber Laser) — **современный стандарт**
- **Длина волны:** 1064 нм
- **КПД:** 30–40% (электричество → луч)
- **Мощность:** 1–30+ кВт
- **Применение:** Сталь, нержавейка, алюминий, медь, латунь, титан
- **Преимущества:** Компактность, надежность, низкие эксплуатационные расходы, отличная качество реза

### 2. CO₂ лазеры (газовые) — **предыдущее поколение**
- **Длина волны:** 10.6 мкм
- **КПД:** 10–15%
- **Мощность:** 1–6 кВт (до 20 кВт на больших станках)
- **Применение:** Сталь, нержавейка, не металлы (дерево, акрил, ткани)
- **Недостатки:** Большие габариты, высокое потребление энергии, сложное обслуживание

### 3. Дисковые лазеры (Disk Laser)
- **Особенности:** Высокая мощность (10–100 кВт), отличное качество пучка
- **Применение:** Толстые листы, высокая производительность

### Сравнение типов для металла:

| Критерий | Fiber Laser | CO₂ Laser |
|----------|-------------|-----------|
| **Резка стали ≤6 мм** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **Резка нержавейки** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **Резка алюминия/меди** | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **Толстый металл (>15 мм)** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **Энергопотребление** | Низкое | Высокое |
| **Обслуживание** | Минимальное | Сложное |
| **Стоимость владения (TCO)** | Низкая | Высокая |

## Материалы для резки

### ✅ Отлично режутся (Fiber Laser):
| Материал | Макс. толщина | Особенности |
|----------|---------------|-------------|
| **Углеродистая сталь** | 25–30 мм | Кислородный газ — высокая скорость |
| **Нержавеющая сталь** | 20–25 мм | Азот — чистый край, без оксидов |
| **Алюминий и сплавы** | 15–20 мм | Требует высокой мощности, азот/воздух |
| **Медь, латунь, бронза** | 6–10 мм | Высокая отражательность, нужен антирефлектор |
| **Титан и сплавы** | 10–15 мм | Азот/аргон, медленная скорость |
| **Гальванизированная сталь** | 3–4 мм | Специальные режимы для цинка |

### ⚠️ Ограничения:
- **Высокоотражательные металлы** (полированная медь, золото, серебро) — риск повреждения оптики
- **Покрытые пленкой материалы** — пленку нужно снимать или использовать специальные режимы
- **Непроводящие материалы** (стекло, керамика, камень) — не режутся волоконными лазерами

## Точность и качество

### Классы точности (по ISO 9013 / GOST):
| Класс | Допуск на размер | Шероховатость (Ra) | Применение |
|-------|------------------|-------------------|------------|
| **1 (Высший)** | ±0.05 мм | 3.2–6.3 мкм | Приборстрой, авиация, медицина |
| **2 (Повышенный)** | ±0.1 мм | 6.3–12.5 мкм | Машиностроение, корпусные детали |
| **3 (Обычный)** | ±0.2 мм | 12.5–25 мкм | Конструкции, несущие элементы |
| **4 (Пониженный)** | ±0.4 мм | 25–50 мкм | Заготовки, черновая обработка |

### Дефекты реза и их причины:
| Дефект | Причина | Решение |
|--------|---------|---------|
| **Налип (дроссель)** | Низкое давление газа, высокая скорость | Увеличить давление, снизить скорость |
| **Заусенцы** | Неправильный фокус, износ сопла | Проверить фокус, заменить сопло |
| **Углеродистый налет** | Кислород на нержавейке | Использовать азот |
| **Деформация** | Избыточный нагрев | Импульсный режим, охлаждение |
| **Полосатость** | Вибрация станка, плохой фокус | Диагностика механики, настройка фокуса |

## Как выбрать подрядчика

### Чек-лист для оценки:
```
☐ Наличие современного волоконно-оптического лазера (не старше 5–7 лет)
☐ Мощность лазера соответствует вашим толщинам (запас 30%)
☐ Размер стола покрывает ваши форматы (стандарт: 1500×3000, 2000×4000, 2000×6000)
☐ Наличие азотной станции / генератора азота (для нержавейки)
☐ Автозагрузка/разгрузка (для серийного производства)
☐ Сертификаты ISO 9001, отраслевые допуски
☐ Собственный конструкторский отдел / инженеры-технологи
☐ Возможность полного цикла: резка → гибка → сварка → покраска
☐ Примеры работ вашей сложности (портфолио, чертежи)
☐ Сроки: типичные 3–7 дней, срочные 1–2 дня
☐ География: доставка по РФ / самовывоз
☐ Оплата: постоплата для проверенных клиентов, НДС 20%
```

### Красные флаги ⚠️:
- Только CO₂ лазеры старого образца
- Нет азотной станции (режут нержавейку кислородом — брак)
- Не выдают протоколы контроля качества
- Не работают с DXF/DWG/STEP файлами
- Требуют 100% предоплату без договора
- Нет физического адреса производства
